# PyCobrança

PyCobrança é o projeto de modernização do PyBoleto, incorporando as melhorias já desenvolvidas na BrCobrança e preparando integração direta com a cobrança_api.

A branch `HML` é o ambiente de homologação e deve concentrar os testes de migração, compatibilidade bancária e integração com API antes de qualquer promoção para produção.
